# RecallFlow - Next.js App Router Language Learning Platform

This is a modern Next.js 14 language learning web application built with TypeScript, Tailwind CSS, Web Audio API, and Speech Synthesis.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
