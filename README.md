# RecallFlow

Türkçe konuşanlar için İngilizce, Almanca ve Fransızca öğrenme deneyimi. Next.js, TypeScript, Tailwind CSS ve Framer Motion ile geliştirildi.

## Özellikler

- 3 dil, A1–C1 arası 5 seviye
- Her dil ve her seviyede 600 kategorize edilmiş kelime/ifade kartı
- Örnek cümleler ve tarayıcı tabanlı seslendirme
- Seviyeli okuma ve dikte stüdyoları
- Türkçeden hedef dile çeviri yapan interaktif robot
- Öğrenilen kartları cihazda saklayan ilerleme sistemi

## Çalıştırma

```bash
npm install
npm run dev
```

Üretim kontrolü: `npm run build`
