# RecallFlow — Kelime Hafıza Stüdyosu

İngilizce, Almanca, Fransızca, İspanyolca ve Portekizce için A1–C2 kelime pratiği. Her seviye kendi temalarına ve hedef sınav rotasına sahiptir; sayaçlar yalnızca gerçek lemma kayıtlarını gösterir.

- Editoryal, yatay kelime atlası
- Sözcük türü, sınav rotası ve beceriye göre aktif görev
- Web Speech API ile hedef dil seslendirmesi
- Türkçeden hedef dile aktif hatırlama robotu
- LocalStorage tabanlı öğrenildi takibi
- 10'luk sayfalama ile kontrollü DOM boyutu
- Sahte varyantları ve seviyeler arası tekrarları reddeden içerik denetimi
