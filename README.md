# RecallFlow — Kelime Hafıza Stüdyosu

İngilizce, Almanca, Fransızca, İspanyolca ve Portekizce için A1–C2 kelime pratiği. Altı kategorinin her dil/seviye kombinasyonunda tam 100 bağlamsal öğrenme birimi bulunur: dil başına seviyede 600, toplamda 18.000 kayıt.

- Editoryal, yatay kelime atlası
- Örnek cümle ve Türkçe karşılığı
- Web Speech API ile hedef dil seslendirmesi
- Türkçeden hedef dile aktif hatırlama robotu
- LocalStorage tabanlı öğrenildi takibi
- 20'lik sayfalama ile kontrollü DOM boyutu
